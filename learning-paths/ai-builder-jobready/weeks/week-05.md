# Week 05 — AI-agents, tool calling en human approval

**8–12 uur | Eindresultaat:** Tool-contract, flowdiagram, tien tests en demo.

## Begrippen
1. chatbot versus agent versus workflow
2. system prompt, context en tools
3. tool schemas en least privilege
4. prompt injection en menselijke goedkeuring

## Leerbronnen
- [Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/)
- [OpenAI tool calling](https://platform.openai.com/docs/guides/function-calling)

| Dag | Activiteit |

## Lab / praktijkopdracht
Bouw een agent of mock-agent die tickets classificeert, een voorstel genereert en expliciete menselijke goedkeuring vraagt. Test onduidelijke input en een poging de instructies te overschrijven.

## Definition of Done
- [ ] Labopdracht uitgevoerd.
- [ ] Bewijs gecommit of gelinkt: Tool-contract, flowdiagram, tien tests en demo.
- [ ] Mijn eigen architectuur-/beslissingsuitleg toegevoegd.
- [ ] Belangrijkste fout en aanpak genoteerd in het learning journal.
- [ ] Weekquiz beantwoord zonder AI.

## Vijf interviewvragen
1. Wat maakt een agent anders?
2. Wat is tool calling?
3. Wat is prompt injection?
4. Waarom least privilege?
5. Wat betekent human-in-the-loop?

## Gate
> Geen belangrijke externe actie zonder expliciete goedkeuring; je kunt dat aantonen.

## Stretch
Ontwerp een edge case waarin jouw oplossing faalt. Beschrijf impact voor gebruiker, beheerder én bedrijf. Laat AI de aannames bekritiseren nadat je het zelf hebt uitgewerkt.
