# Week 02 — Python, SQL en REST API bouwen

**8–12 uur | Eindresultaat:** Werkende lokaal gestarte API, 5 SQL-query's, test en commit.

## Begrippen
1. Python functies, exceptions en venv
2. SQLite: tabellen, keys, WHERE, JOIN
3. SQL-parameters en inputvalidatie
4. REST endpoints en 422/404 responses

## Leerbronnen
- [Python tutorial](https://docs.python.org/3/tutorial/)
- [SQLBolt](https://sqlbolt.com/)
- [FastAPI](https://fastapi.tiangolo.com/tutorial/)

## Lab / praktijkopdracht
Start de meegeleverde FastAPI/SQLite-capstone. Maak 5 eigen SELECT-query's. Schrijf een test voor een statusfilter, implementeer het en test ongeldige waarden.
