# Implementation Handoff Template

```yaml
task_id: "<same task id as approved research>"
objective: "<implemented objective>"
scope:
  in_scope:
    - "<completed area or behavior>"
  out_of_scope:
    - "<preserved non-goal>"
acceptance_criteria:
  - criterion: "<condition>"
    status: "passed"
files_involved:
  - "<created or modified path>"
risks:
  - "<remaining risk or none>"
evidence:
  - command: "<validation command>"
    result: "<exact result>"
approval_status: "pending"
```

## Implementation output

- Summary of changes:
- Compatibility impact:
- Documentation impact:
- Tests added or updated:
- Known limitations:
- Requested next role: `Repository Tester`

The Developer must not commit, push, merge, deploy, or release. The Tester
should re-read the repository and verify the evidence independently.
